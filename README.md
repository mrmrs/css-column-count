# css-column-count

Functional CSS for column-count

## Filesize

| File | Size |
|------|------|
| `dist/column-count.css` | 2849 bytes |
| `dist/column-count.min.css` | 1917 bytes (329 Gzipped) |

## Install

```sh
npm install css-column-count
```

## Usage

### Import

```css
@import "css-column-count";
```

### CDN

```html
<link rel="stylesheet" href="https://unpkg.com/css-column-count/dist/column-count.min.css">
```

### Direct

```html
<link rel="stylesheet" href="path/to/css-column-count/dist/column-count.min.css">
```

### Responsive

Responsive variants are available for each class with the following suffixes:

| Suffix | Media Query              |
|--------|--------------------------|
| `-s`   | `min-width: 32em`        |
| `-m`   | `min-width: 48em`        |
| `-l`   | `min-width: 96em`        |

Example: `.column1-m` applies the property at the medium breakpoint and above.

## Building

```sh
npm run build
```

Processes `src/column-count.css` with [Lightning CSS](https://lightningcss.dev) and outputs to `dist/`.

- `dist/column-count.min.css` — minified
